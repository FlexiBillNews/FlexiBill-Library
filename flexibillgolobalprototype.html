The operating rule

Balance DOKU ↔ Antom
DOKU owns once: platform core, adapter contracts, package templates, global governance, release gates and operational truth.
Antom owns once: dashboard socket, host SSO token, merchant onboarding event, merchant payment trigger, settlement handshake and product activation.
Country owns locally: what to sell, local rails, localization, finance approval and rollout timing — but never forks the billing engine.

What must never fork

The anti-drift boundary

Do not fork: Billing Automation, Billing Recurring, subscription state machine, bill generation, recurring logic, shared package semantics, or the contract definitions. Forking these would turn Model 1 into Model 3-by-stealth.
Version once: contract schemas, package capability IDs and feature-state vocabulary.

Conditional residency layer

When does the MY cell appear?

Only when required. Keep the core global and shared. Instantiate the country cell when data residency, local operation or regulatory policy requires local infrastructure. This is the Model 3 layer used as a condition, not the default architecture.
